# 📱 Phone Store Management System

A simple phone store management system built using JavaScript Arrays and basic CRUD operations.

## 🌐 Live Demo

[View Live Website](YOUR_LIVE_DEMO_LINK)

## 🛠️ Technologies Used

- HTML5
- BOOTSTRAP
- JavaScript

## ✨ Features

- Add new phones to the store.
- Display all available phones.
- Edit existing phone information.
- Delete phones from the collection.
- Input validation to prevent invalid entries.

## 🚀 Getting Started

1. Clone the repository:

   git clone [https://github.com/Moataz007/phone_storage_-arr_task-.git]

2. Open the project folder.

3. Open `index.html` in your browser.

## 🎯 Project Goal

The goal of this project was to practice JavaScript fundamentals by building a simple phone store management system. It focuses on working with Arrays, implementing CRUD operations, and handling user input with basic validation.
